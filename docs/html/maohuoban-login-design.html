IP 形象

品牌 IP 视觉资产说明。在业务界面呈现中，已移除具体的宠物图片元素，在此保留形象设定说明。

品牌伙伴形象 — 小白犬「毛毛」

毛毛是毛伙伴的核心 IP 形象，它是一只软糯可爱的白色幼犬，手捧一颗象征呵护与关爱的蓝色爱心，有着大大的黑色眼睛和顽皮眨眼的生动神态。

设计语境：友好、可信赖、克制、富有温度
核心作用：在 App 的引导页、数据空状态及医疗照护服务页面担任友好助理的角色
视觉原则：小白犬通体使用冷白配色的渐变柔化毛发，搭配品牌蓝色心形配饰
