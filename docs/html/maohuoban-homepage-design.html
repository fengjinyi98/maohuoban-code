设计说明与交互规范

本页面规范为毛伙伴（Maohuoban）首页，采用极简的 Apple Health 与 Notion 混合拟物卡片结构。主调使用低饱和度冷色系，通过细微的渐变与 75% 白色半透明磨砂玻璃卡片营造极具深度与呼吸感的层次。

交互指引
开启红线规范后，点击左侧 iPhone 页面中的蓝色序号标记，即可在此处查看具体组件的设计规范并定位代码。
组件代码浏览器 (HTML/CSS) 
/* 点击左侧 iPhone 中的任何组件卡片或序号以浏览代码 */
.card-inset {
  background: rgba(255, 255, 255, 0.75);
  backdrop-filter: blur(20px) saturate(1.6);
  border: 0.5px solid rgba(255, 255, 255, 0.6);
  border-radius: 16px;
  box-shadow: 0 4px 20px rgba(0,0,0,0.015);
}

页面设计 Token 值 (与系统一致)

首页所有界面元素使用系统全局 Design Token 渲染，禁用非系统预设色彩，确保视觉统一。

Token 名称 预设色彩值 对应 CSS 属性 场景用途
Primary Color
#4F8CFF
 --primary 选中状态、核心高亮、主按钮
Success
#34C759
 --green 今日照护正常、已接种、可售状态
Warning
#FF9500
 --orange 日程待办、异常关注、已预定状态
Danger
#FF3B30
 --red 紧急预警、疾病护理、通知数字角标
Secondary Blue
#5AC8FA
 --teal 排泄正常指标、医疗协同标记
Background
#F7F9FC
 --bg 页面冷白蓝主背景
Glass Card
75% White + Blur
 --card 所有内容卡片磨砂玻璃层
Text Primary
#1A1D26
 --l1 主标题、关键大字、数值内容
Text Secondary
#6E7681
 --l2 辅助说明、卡片副标题
