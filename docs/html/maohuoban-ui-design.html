设计语言

Apple Health · Wallet · Tesla · Notion 风格融合。

核心原则

01Frosted Glass 全局 — 所有卡片 75% 白 + blur(20px)，页面背景可透出
02冷蓝低饱和 — 主色 #4F8CFF 仅交互态，功能色使用 iOS 系统色
03微妙光晕 — 背景大面积模糊渐变色块 (orb) 营造深度
04Hairline 分层 — 0.5px border 区分层级，阴影仅品牌元素使用
05渐变图标 — 列表/快捷动作图标使用 linear-gradient 填充
06内容即温度 — 冷色 UI 框架 + 暖色宠物照片形成视觉张力
