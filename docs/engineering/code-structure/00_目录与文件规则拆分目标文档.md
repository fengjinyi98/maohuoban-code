| 范围 | 目标 |

| P1 Swift | 所有超过 400 行的 Swift 文件完成拆分，或在同目录补明确豁免理由 |

| 暂不做 | 原因 |

| 业务逻辑重写 | 本目标只处理文件边界和职责拆分 |

## 7. 验收门禁

| 类型 | 命令 / 验收 |
|---|---|
| Swift P1 扫描 | `git ls-files '*.swift' | xargs wc -l | awk '$2 != "total" && $1 > 400 {print $1, $2}'` 输出为空或仅包含豁免文件 |
| Rust P1 扫描 | `git ls-files '*.rs' | xargs wc -l | awk '$2 != "total" && $1 > 500 {print $1, $2}'` 输出为空或仅包含豁免文件 |
| iOS Debug 构建 | `xcodebuild -project maohuoban/maohuoban.xcodeproj -scheme maohuoban -destination 'platform=iOS Simulator,name=iPhone 17 Pro,OS=27.0' -configuration Debug build` 以 `** BUILD SUCCEEDED **` 结束 |

| Rust 格式 | `cd maohuoban-rust && cargo fmt --all --check` |
| Rust 编译 | `cd maohuoban-rust && cargo check --workspace --all-targets` |
| Rust 测试 | 修改后端行为边界时运行 `cd maohuoban-rust && cargo test --workspace` |
| 行为一致性 | 拆分前后公开类型、路由、DTO、SwiftUI 页面入口和测试断言保持等价 |

## 8. 不变约束

| 约束 | 说明 |
|---|---|
| 只做结构拆分 | 不借机重写业务流程、视觉、导航或 API 语义 |
| View 纯渲染 | SwiftUI `body`、同步 formatter、selector、resolver 仍保持无副作用 |
| 系统导航 | 不引入自绘导航替代系统 `NavigationStack` / 系统返回手势 |
| UIKit 边界 | 不为普通 SwiftUI 拆分新增 UIKit 桥接 |
| 访问控制 | 拆出的 helper 默认 `private` / `fileprivate` / internal 最小暴露 |
| 测试有效 | 拆分后的测试仍验证原行为，不把断言降级为存在性检查 |
| 用户改动保护 | 当前主工作区已有未提交改动不在拆分分支内回滚或覆盖 |

## 9. 风险

| 风险 | 处理 |
|---|---|
| 大文件拆分引入访问级别扩散 | 每次只开放编译必需的最小符号，优先同目录 internal 或 private helper |
| SwiftUI 子 View 拆出后状态传递膨胀 | 只传子 View 实际读取数据，命令通过显式闭包转发 |
| Rust 模块拆分破坏可见性 | 先建立 `mod` 结构，再逐个移动函数和类型，保持 public API 不变 |
| 构建耗时导致反馈慢 | 按 Feature / crate 切片验证，最终再跑完整门禁 |
| 当前工作区有未提交改动 | 在 `.worktree/file-rules-split` 独立分支实施，主工作区只保留文档和审查产物 |
