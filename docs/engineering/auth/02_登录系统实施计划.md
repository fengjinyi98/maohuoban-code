# 登录系统实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成毛伙伴验证码登录、密码登录、忘记密码、双 token 会话、前端登录 UI、toast 反馈和端到端验证。

**Architecture:** 后端采用 Rust workspace crates + 分层架构，`maohuoban-auth-domain` / `maohuoban-auth-application` / `maohuoban-auth-infrastructure` / `maohuoban-auth-http` / `maohuoban_rust` 装配层分离；iOS 采用 MVVM 与单向数据流，网络、Keychain、Toast 归入基础设施；验证码短期状态使用 Redis，身份与 session 使用 PostgreSQL。

**Tech Stack:** Rust 2024、axum、sqlx、PostgreSQL、Redis、argon2、JWT/PASETO 风格 token、Swift 6.4、SwiftUI、UIKit、MaohuobanDesignSystem、MaohuobanDiagnostics。
