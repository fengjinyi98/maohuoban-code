# 首页与宠物工作台实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成毛伙伴首页前后端可扩展骨架，覆盖普通用户宠物主体页、新用户空态、认证商家多宠工作台、宠物事件底座、窝次追溯边界、首页聚合接口和质量门禁。

**Architecture:** 后端采用 Rust workspace crates + 分层架构，新增 pet/home 相关 domain/application/infrastructure/http crates；iOS 采用 Home Feature 下的 Domain/Data/Stores/Presentation 分层，`HomeRootScreen` 只组合 section views；首页通过 `HomeDashboardSnapshot` 聚合读模型驱动。

**Tech Stack:** Rust 2024、axum、sqlx、PostgreSQL、uuid、Swift 6.4、SwiftUI、UIKit、MaohuobanDesignSystem、MaohuobanDiagnostics。
