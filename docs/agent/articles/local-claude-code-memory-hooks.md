# Claude Code 长期项目记忆：4 个 Markdown 文件 + 3 个 Hooks

- 来源：docs/agent/1.md
- 保存时间：2026-06-28
- 类型：本地原始文章整理

---

用 Claude Code 做长期项目的人应该都遇到过这种情况：上次明明说过项目规则。
这次又忘了。上次明明踩过这个坑。
这次又犯一遍。上次做到一半的任务。
下次打开还要重新解释。上次已经确认过的输出格式。
新会话又变回默认风格。这就是典型的 Agent “失忆”。但解决思路不一定复杂。你可以先用本地最朴素的办法跑起来：4 个 Markdown 文件 + 3 个 hooks。它的核心是：把 Claude 每次需要记住的东西，拆成规则、进度、教训和共识，再让 hooks 在关键节点自动读写。1️⃣ 先说清楚：这不是“无限记忆”这套方法不是让 Claude 真的拥有永久大脑。它更像是给 Claude Code 项目目录里放一套“工作档案”。每次会话开始，让它先读。
每次工具使用后，把关键动作记下来。
每次会话结束，让它写总结。
下次再开工，就不用从零解释。所以更准确的说法是：不是 Claude 真的不会忘，而是你把它该记住的东西写成了可读文件。这就已经足够解决很多问题了。2️⃣ 4 个 md 分别管什么？不要把所有记忆都塞进一个文件。那样很快就乱。建议拆成 4 个 Markdown 文件：CLAUDE.md
Memory.md
Learning.md
Wiki.md
CLAUDE.md
Memory.md
学习.md
Wiki.md它们分工不同。3️⃣ CLAUDE.md：立规矩第一个文件是：CLAUDE.md它负责告诉 Claude：这个项目是什么。
你应该怎么做事。
哪些文件不能乱动。
输出格式是什么。
常用命令是什么。
哪些规则必须遵守。你可以把它理解成：Agent 的项目说明书。适合放这些内容：项目背景
目录结构
编码规范
写作风格
常用命令
禁止行为
提交规范
输出格式
人工确认规则4️⃣ Memory.md：记进度第二个文件是：Memory.md它负责记录每次 session 结束后的状态。比如：这次完成了什么
修改了哪些文件
还有什么没做
下次从哪里继续
哪些问题需要用户确认你可以把它理解成：Agent 的交接班记录。5️⃣ Learning.md：错题本第三个文件是：Learning.md它不是记进度，而是记教训。比如：上次踩过什么坑
用户纠正过什么
某个命令不能用
某个路径不要动
某个输出方式不适合
某个判断曾经错过
出现过什么 aha moment你可以把它理解成：Agent 的错题本。6️⃣ Wiki.md：共享背景墙第四个文件是：Wiki.md它负责存放长期共识。比如：项目术语
业务规则
产品定位
用户画像
品牌规范
内容栏目
关键决策
多个 Agent 都要知道的背景你可以把它理解成：给所有 Agent 看的共享墙。7️⃣ 再配 3 个 hooks，记忆才真正跑起来只有 md 文件还不够。你还需要让 Claude 在关键时刻自动读写。可以按 3 个节点来理解：SessionStart
PostToolUse
SessionEnd
会话开始
PostToolUse
会话结束8️⃣ SessionStart：开工前先读记忆SessionStart 是会话开始。这个阶段最适合做：读取 CLAUDE.md
读取 Memory.md
读取 Learning.md
读取 Wiki.md
总结当前任务背景
提醒上次未完成事项你可以让它执行类似逻辑：会话开始时，请先读取：
1. CLAUDE.md
2. Memory.md
3. Learning.md
4. Wiki.md

然后输出：
- 当前项目规则
- 上次进度
- 需要避免的坑
- 重要项目共识
- 本次建议优先处理的任务SessionStart 的价值是让 Claude 开工前先看上下文。9️⃣ PostToolUse：干完一步就记一下PostToolUse 是工具使用之后。比如 Claude 修改了文件、运行了命令、生成了结果。这时候最适合记录：刚才做了什么
改了哪些文件
命令是否成功
有没有报错
有没有新踩坑
是否需要写入 Learning.md可以设置类似要求：每次工具使用后，请记录：
1. 工具名称
2. 执行动作
3. 影响文件
4. 是否成功
5. 报错信息
6. 是否产生新经验
7. 是否需要追加到 Learning.mdPostToolUse 的价值，是把过程留痕。否则任务跑完，你只看到结果，看不到中间发生了什么。🔟 SessionEnd：收工时写总结SessionEnd 是会话结束。这个阶段最适合写 Memory.md。每次结束都让 Claude 写一笔：本次完成什么
未完成什么
修改了什么
下次从哪里继续
有哪些待确认问题
有哪些教训要追加到 Learning.md模板可以这样：markdown
Markdown 格式会话结束时，请更新 Memory.md。

请追加本次总结：

2. 已完成事项
